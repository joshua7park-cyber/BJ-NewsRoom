# BJ 인텔리전스 뉴스룸

매일 08:00 아침판. 세상의 흐름을 균형 있게 읽는 기본 4대 섹션(경제 · 정치·사회 · 테크·산업 · 국제)에 BJ 관심 섹션(이스라엘·중동 · 종교·선교 · 과학)을 더했습니다. 모든 기사에 교차검증 등급(A/B/C)과 출처를 붙이고, 분야별 교육·세미나 일정을 함께 싣습니다.

공개 주소: https://joshua7park-cyber.github.io/BJ-NewsRoom/

## 화면 구성

밝은 카드형 포털 디자인입니다. 보도 사진은 저작권 때문에 쓰지 않고 섹션 아이콘과 핵심 숫자로 대신하며, 조회수 데이터가 없으므로 "많이 본 뉴스" 대신 편집 우선순위와 출처 수를 보여 줍니다.

1. **대문 슬라이드**: 1~3번 기사, 화살표로 넘기며 오른쪽에 기사 본문에서 가져온 핵심 숫자
2. **섹션 타일**: 전체와 7개 섹션, 누르면 해당 섹션만 보기
3. **Featured**: 4~6번 기사 카드
4. **오늘의 검증 뉴스**: 기본 4대 섹션과 BJ 관심 섹션, 섹션마다 "왜 보나"와 체크 포인트, 그 자리에서 펼쳐 읽기, 해당 분야 세미나
5. **오른쪽 열 (오늘 아침 5분)**: 오늘의 3줄 → 오늘의 지표 → 관전 포인트 → 5분 헤드라인 → 검증 배너(게재·A급·확인 중·세미나·보류 숫자) → 검증 보류 → 출처 구성
6. **데스크 보기**: 섹션별 보드로 제목만 훑기
7. **교육·세미나 달력**(날짜순)과 **실시간 제목 색인**(자동 수집, 검증 전)

## 운영본은 하나

| 파일 | 역할 |
|---|---|
| `index.html` | 유일한 운영 페이지. 기사 내용은 들어 있지 않습니다. |
| `data/edition.json` | 오늘 아침판: 3줄 요약, 지표, 기사, 교육·세미나, 관전 포인트, 검증 보류 |
| `site/newsroom.json` | 매시간 자동 수집하는 실시간 제목 색인 (검증 전, 페이지 하단에 따로 표시) |
| `site/link-report.json` | 배포 때 생성되는 링크 점검 결과 (저장소에는 없음) |
| `EDITOR_GUIDE.md` | 매일 아침 편집 세션이 따르는 지침 (섹션 구성, 등급, 지표 규칙) |

## 매일 흐름

1. **06:40 KST** Claude 예약 작업이 `EDITOR_GUIDE.md`대로 뉴스·지표·교육 일정을 조사하고 `data/edition.json`을 새로 씁니다 (07:45까지 반영).
2. 편집 세션은 `validate_edition.py --require-today`와 테스트를 통과한 경우에만 `main`에 푸시합니다.
3. 푸시하면 **BJ Newsroom Deploy**가 검사를 차례로 실행하고, 하나라도 실패하면 배포를 멈춥니다.
   1. 아침판 데이터 검사 (섹션·체크 포인트, 핵심 정리 3~5개, 제목 길이, 4일 이내 기사, 국내 A급의 주요 매체 출처, 요일, 핵심 숫자 대조, 실제 발행 시각, 세미나 링크 종류)
   2. 회귀 테스트 (승인된 A+C 화면 유지 포함)
   3. 페이지 자바스크립트 문법
   4. 모든 출처·세미나·지표 링크 열람 (A급 기사는 열리는 출처 2곳 이상, 확정 세미나는 신청·주최 링크가 열려야 함)
   5. 배포 후 공개 주소에서 페이지와 JSON 3종 응답 확인
4. **07:58 KST** 보고 예약 작업이 게재 결과(기사 수, 등급, 링크 점검, 세미나)를 BJ님께 알리고, **08:09 KST**에 같은 검사를 한 번 더 실행해 공개 페이지를 재확인합니다.
5. 매시간 `refresh-news.yml`이 제목 색인을 갱신합니다. 아침판 기사와는 섞이지 않습니다.

아침판이 발행되지 않은 날에는 전날 판이 "오늘판 발행 전" 표시와 함께 그대로 보입니다. 빈 화면이나 임시 기사는 나오지 않습니다.
